📚 Library System – Assessment 2 (ICT0008)

A simple Library Management System in C++ for the ICT0008 – Advanced Programming Skills course.
Features include adding, listing, sorting, and searching books via a console-based interface.

🚀 How to Run

Clone the repository:

git clone https://github.com/rhuanpfig/Assessment2.git


Open LibrarySystem.sln in Visual Studio.

Build and run the project (Ctrl + F5).
